## Установка

1. Скачайте архив из раздела **Releases**.
2. Распакуйте архив.
3. Скопируйте папку `atmosphere` в корень microSD Nintendo Switch.
4. Подтвердите объединение папок.
5. Запустите игру через Atmosphère.

Путь установки:

```text
atmosphere/contents/01009B50139A8000/romfs/
```
